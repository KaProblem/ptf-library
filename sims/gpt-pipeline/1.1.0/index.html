Station 3 · Shapes

What shape is the tensor?

A training batch has B = 4 sequences of T = 8 characters. Each vector has C = 32 numbers, there are 4 heads of size 8, and the vocabulary has V = 65 characters. Pick the shape at each point.

Station 4 · Writing in a window

The context window

Generation repeats the whole pipeline once per character: predict, append, repeat. But the model has only a fixed number of position embeddings, here 8. Everything before the last 8 characters falls out of view. Write a few characters and watch the window slide.

Station 5 · What learns?

Learned or fixed?

Training only changes numbers that the model owns: its parameters. Which parts have them, and which are fixed rules that never change? Decide for each part.
