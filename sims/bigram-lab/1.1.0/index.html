Station 1 · How good is the model?Station 1 · Wie gut ist das Modell?

The lossDer Loss

For every real next character we ask: what probability p did the model give it? The loss is −ln(p), averaged over the text. Confident, correct predictions give almost 0; surprises give large values.Für jedes echte nächste Zeichen fragen wir: Welche Wahrscheinlichkeit p hatte das Modell ihm gegeben? Der Loss ist −ln(p), gemittelt über den Text. Sichere, richtige Vorhersagen ergeben fast 0, Überraschungen große Werte.

Guess first:Erst raten: Which text gets the lower loss: a line from the play, or letter salad of the same length?Welcher Text bekommt den kleineren Loss: eine Zeile aus dem Stück oder gleich langer Buchstabensalat?

In code: loss = F.cross_entropy(logits.view(B*T, C), targets.view(B*T)) is exactly this average of −ln p over all positions.Im Code: loss = F.cross_entropy(logits.view(B*T, C), targets.view(B*T)) ist genau dieser Mittelwert von −ln p über alle Positionen.

Station 2 · TrainingStation 2 · Training

Read more text, be less surprisedMehr Text gelesen, weniger überrascht

For a bigram model, training is just counting. The slider sets how much of the training text the model has read so far. The loss is measured on the last 10 % of the text, which it never reads (validation).Beim Bigramm ist Training einfach Zählen. Der Regler stellt ein, wie viel vom Trainingstext das Modell schon gelesen hat. Gemessen wird der Loss auf den letzten 10 % des Texts, die es nie liest (Validierung).

Guess first:Erst raten: Before it has read a single character, what is the model's validation loss?Bevor es ein einziges Zeichen gelesen hat: Wie groß ist der Validierungs-Loss des Modells?

For comparison: trained on all of Shakespeare (over 1 million characters, 65 different), a bigram model ends at about 2.5. A small GPT reaches about 1.5 on the same data because it looks back much further than one character.Zum Vergleich: Mit dem ganzen Shakespeare (gut 1 Million Zeichen, 65 verschiedene) landet ein Bigramm bei etwa 2,5. Ein kleines GPT schafft auf denselben Daten etwa 1,5, weil es viel weiter als ein Zeichen zurückschaut.

Station 3 · TemperatureStation 3 · Temperatur

Bold or careful samplingMutig oder vorsichtig würfeln

Before rolling the die, the distribution can be sharpened or flattened. That setting is called temperature; 1 leaves the counted probabilities as they are.Vor dem Würfeln kann man die Verteilung schärfen oder glätten. Diese Einstellung heißt Temperatur; 1 lässt die gezählten Wahrscheinlichkeiten, wie sie sind.

Guess first:Erst raten: At a very low temperature (0.1), what does the generated text look like?Wie sieht der erzeugte Text bei sehr niedriger Temperatur (0,1) aus?

Then try a high temperature, around 2.5, and compare.Probier dann eine hohe Temperatur um 2,5 und vergleiche.

In code the logits are divided by the temperature before softmax: probs = F.softmax(logits / T, dim=-1). For counted probabilities that is the same as raising each p to the power 1/T and renormalising.Im Code werden die Logits vor dem Softmax durch die Temperatur geteilt: probs = F.softmax(logits / T, dim=-1). Für gezählte Wahrscheinlichkeiten ist das dasselbe, wie jedes p hoch 1/T zu nehmen und neu zu normieren.

Station 4 · The table behind it allStation 4 · Die Tabelle hinter allem

The model is a V×V tableDas Modell ist eine V×V-Tabelle

Each row belongs to the current character, each column to a possible next one. The brighter a cell, the more likely that pair.Jede Zeile gehört zum aktuellen Zeichen, jede Spalte zu einem möglichen nächsten. Je kräftiger eine Zelle, desto wahrscheinlicher das Paar.

Guess first:Erst raten: The text has V = 48 different characters. How many numbers does the whole model hold?Der Text hat V = 48 verschiedene Zeichen. Wie viele Zahlen enthält das ganze Modell?

In PyTorch this is nn.Embedding(vocab_size, vocab_size): the row of the current character is looked up and read as logits (raw scores) that softmax turns into probabilities. A network trained by gradient descent ends up with almost the same table as counting; the network only pays off once more than one character of context comes in.In PyTorch ist das nn.Embedding(vocab_size, vocab_size): Die Zeile des aktuellen Zeichens wird nachgeschlagen und als Logits (rohe Punktzahlen) gelesen, die Softmax in Wahrscheinlichkeiten umrechnet. Ein per Gradientenabstieg trainiertes Netz landet fast bei derselben Tabelle wie das Zählen; das Netz lohnt sich erst, wenn mehr als ein Zeichen Kontext dazukommt.
