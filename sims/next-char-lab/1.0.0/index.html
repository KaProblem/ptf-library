Lernsession „Wie GPT funktioniert“ · Simulator 1

Nächstes-Zeichen-Labor

Ein Sprachmodell macht nur eins: Es schätzt, welches Zeichen als Nächstes kommt. Hier baust du das einfachste solche Modell selbst, ein Bigramm-Modell, so wie Karpathy es im Video als Startpunkt nimmt.

Video: Let's build GPT, Abschnitt 0:07–0:42v1
Station 1 · Text wird zu Zahlen

Der Tokenizer

Das Modell sieht keine Buchstaben, nur Zahlen. Jedes Zeichen, das im Trainingstext vorkommt, bekommt eine Nummer. Das ist das ganze „Vokabular“.

Station 2 · Was kommt danach?

Gezählte Wahrscheinlichkeiten

Das Bigramm-Modell schaut nur auf das letzte Zeichen und fragt: Was kam im Trainingstext danach, und wie oft? Tipp ein Zeichen oben in Station 1 an oder wähle hier eins.

Station 3 · Würfeln

Text erzeugen, Zeichen für Zeichen

Erzeugen heißt: Wahrscheinlichkeiten ausrechnen, einmal gewichtet würfeln, das Ergebnis anhängen, wiederholen. Vergleich ein Modell, das nichts gelernt hat, mit dem gezählten.

Prüf dich: Warum ist der Bigramm-Text immer noch Unsinn?

Weil das Modell nur das allerletzte Zeichen kennt. Nach „e“ weiß es, dass oft ein Leerzeichen oder „r“ kommt, aber nicht, welches Wort gerade entsteht. Genau das löst später die Attention: Die Zeichen dürfen in ihren Kontext zurückschauen.

Station 4 · Wie gut ist das Modell?

Der Loss

Für jedes echte nächste Zeichen fragen wir: Welche Wahrscheinlichkeit hatte das Modell ihm gegeben? Der Loss ist −ln(p), gemittelt. Sichere, richtige Vorhersagen ergeben fast 0, Überraschungen große Werte. Rot heißt: Das Modell war überrascht.

Station 5 · Training

Mehr Text gelesen, weniger überrascht

Beim Bigramm ist „Training“ einfach Zählen. Schieb den Regler: So viele Zeichen des Trainingstexts hat das Modell schon gesehen. Gemessen wird auf den letzten 10 %, die es nie sieht (Validierung).

Im Video startet das neuronale Bigramm bei 4,87 (zufällige Gewichte, etwas schlechter als Raten mit ln 65 ≈ 4,17) und landet nach dem Training auf 1 Mio. Zeichen bei etwa 2,5. Mit unserem kleinen Auszug kommt man nicht ganz so weit.

Station 6 · Temperatur

Mutig oder vorsichtig würfeln

Vor dem Würfeln kann man die Verteilung schärfen oder glätten. Niedrige Temperatur nimmt fast immer das Wahrscheinlichste, hohe macht alles gleich wahrscheinlich.

Station 7 · Trainingsbeispiele

Ein Ausschnitt, viele Beispiele

Trainiert wird auf Ausschnitten der Länge block_size + 1. Darin stecken block_size Beispiele: Kontext → nächstes Zeichen. y ist einfach x um eins verschoben. Markiert ist das, was das Bigramm davon tatsächlich benutzt.

Station 8 · Die Tabelle hinter allem

Das Modell ist eine V×V-Tabelle

Jede Zeile gehört zu einem Zeichen, jede Spalte zum möglichen Nachfolger. Im Video ist das nn.Embedding(vocab_size, vocab_size): Die Zeile wird nachgeschlagen und als Logits gelesen. Hier stehen die gezählten Wahrscheinlichkeiten drin. Tipp eine Zelle an.

Tipp eine Zelle an.
class BigramLanguageModel(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.token_embedding_table = nn.Embedding(vocab_size, vocab_size)
    def forward(self, idx, targets=None):
        logits = self.token_embedding_table(idx)   # (B, T, C)
        ...
        loss = F.cross_entropy(logits.view(B*T, C), targets.view(B*T))
Prüf dich: Was ist der Unterschied zwischen dieser Tabelle und Karpathys trainiertem Bigramm?

Inhaltlich fast keiner. Er lernt die Tabelle per Gradientenabstieg statt sie zu zählen, landet aber bei derselben Lösung: Softmax der gelernten Zeile ≈ gezählte Häufigkeit. Das Netz-Gerüst lohnt sich erst, wenn mehr als ein Zeichen Kontext ins Spiel kommt.
