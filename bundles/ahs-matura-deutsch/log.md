# Log

- 2026-11-05: Version 0.1.0. Bundle created: 12 elements (exam format, assessment grid, argumentation, structure and style, language accuracy, and the seven text types Zusammenfassung, Leserbrief, Kommentar, Erörterung, Meinungsrede, Textanalyse, Textinterpretation), 77 questions, the learning path `matura-course`. Every text type has a full original writing task with a rubric along the four dimensions of the SRDP assessment grid and a sample text. `checks/` recomputes the numbers and checks that every sample text fits its word range, uses only figures from its Textbeilage and quotes it word for word. The official SRDP documents could not be fetched from the cloud environment; format and grid were taken from search results and secondary sources and should be compared with the current documents on matura.gv.at before the element status is raised.
