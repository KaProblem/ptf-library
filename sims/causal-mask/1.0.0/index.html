Nur die Vergangenheit zählt

Ein Sprachmodell soll an jeder Stelle das nächste Zeichen vorhersagen. Dafür darf jede Stelle Informationen von früheren Stellen einsammeln, aber niemals von späteren: Dort steht ja die Lösung. Hier baust du den einfachsten Weg, das zu tun, und siehst, wie daraus ein Werkzeug wird, das Attention heißt.

Station 1 · Ausprobieren

Mittelwert der Vergangenheit

Jede der acht Stellen trägt eine Zahl, stell sie dir als eine Eigenschaft des Zeichens vor. Die einfachste Art, Vergangenheit einzusammeln: Jede Stelle nimmt den Mittelwert aus sich selbst und allen Stellen davor. Tipp eine Stelle an.

Frage: Welchen Mittelwert bekommt Stelle 5?

Station 2 · Als Tabelle

Das Dreieck

Schreib die Mittelwerte als Tabelle von Gewichten: Zeile = die Stelle, die einsammelt, Spalte = die Stelle, von der gelesen wird. Jede Zeile verteilt 100 % gleichmäßig auf sich und ihre Vergangenheit. Oben rechts bleibt alles leer: Das ist die Zukunft. Tipp ein leeres Feld an, um die Zukunft zu öffnen, und schau, was passiert.

Rechnerisch ist das eine Matrixmultiplikation: Gewichte (8 × 8) mal Zahlen (8 × 1) ergibt alle acht Mittelwerte auf einmal. Weil die untere Dreiecksmatrix die Zukunft ausblendet, heißt sie kausale Maske.

Station 3 · Gewichte, die lernen können

Punkte, Maske, Softmax

Gleichmäßige Gewichte sind langweilig: Vielleicht interessiert Stelle 6 sich viel mehr für Stelle 2 als für den Rest. Dafür vergibt man Punkte (Affinitäten), setzt alle Zukunftsfelder auf −∞ und wendet in jeder Zeile Softmax an. Mit allen Punkten auf 0 kommt genau das Dreieck aus Station 2 heraus. Verschieb die Punkte für Zeile 6.

wei = q @ k.transpose(-2, -1)            # Punkte (B, T, T)
wei = wei.masked_fill(tril == 0, float("-inf"))  # Zukunft sperren
wei = F.softmax(wei, dim=-1)              # jede Zeile summiert zu 1
out = wei @ v                             # gewichteter Mittelwert

Warum −∞ und nicht 0? Softmax rechnet ePunkte. e0 = 1 wäre ein normales Gewicht, nur e−∞ = 0 sperrt ein Feld wirklich. Die Punkte selbst kommen beim Transformer aus Query mal Key, das ist der nächste Schritt.
