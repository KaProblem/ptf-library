Prüf dich: Warum ist der Bigramm-Text immer noch Unsinn?

Weil das Modell nur das allerletzte Zeichen kennt. Nach „e“ weiß es, dass oft ein Leerzeichen oder „r“ kommt, aber nicht, welches Wort gerade entsteht. Genau das löst später die Attention: Die Zeichen dürfen in ihren Kontext zurückschauen.

Wie gut ist das Modell?

Der Loss

Rot heißt: Das Modell war überrascht. Der Loss misst diese Überraschung, gemittelt über den Satz.

Wie wird gerechnet?

Für jedes echte nächste Zeichen nehmen wir die Wahrscheinlichkeit p, die das Modell ihm gegeben hat. Der Loss ist −ln(p): fast 0 bei einer sicheren, richtigen Vorhersage, groß bei einer Überraschung.

Zum Vergleich

Mit dem kompletten Shakespeare (gut 1 Mio. Zeichen, 65 verschiedene) landet ein Bigramm bei etwa 2,5. Ein kleines GPT schafft auf denselben Daten ungefähr 1,5, weil es weit mehr als ein Zeichen zurückschaut.

Trainingsbeispiele

Ein Ausschnitt, viele Beispiele

Trainiert wird auf Ausschnitten der Länge block_size + 1. Darin stecken block_size Beispiele: Kontext → nächstes Zeichen. y ist einfach x um eins verschoben. Markiert ist das, was das Bigramm davon tatsächlich benutzt.

So sieht das in PyTorch aus

Die Tabelle ist nn.Embedding(vocab_size, vocab_size): Die Zeile des aktuellen Zeichens wird nachgeschlagen und als rohe Punktzahlen („Logits“) gelesen, die Softmax in Wahrscheinlichkeiten umrechnet.

class BigramLanguageModel(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.token_embedding_table = nn.Embedding(vocab_size, vocab_size)
    def forward(self, idx, targets=None):
        logits = self.token_embedding_table(idx)   # (B, T, C)
        ...
        loss = F.cross_entropy(logits.view(B*T, C), targets.view(B*T))
Prüf dich: Was ist der Unterschied zwischen dieser Tabelle und einem Bigramm, das als neuronales Netz trainiert wird?

Inhaltlich fast keiner. Das Netz lernt die Tabelle per Gradientenabstieg statt sie zu zählen, landet aber bei derselben Lösung: Softmax der gelernten Zeile ≈ gezählte Häufigkeit. Das Netz-Gerüst lohnt sich erst, wenn mehr als ein Zeichen Kontext ins Spiel kommt.

Zusammenfassung

Das Wichtigste aus Stufe Einsteiger

1. Ein Sprachmodell sagt das nächste Zeichen (oder Token) voraus, mehr nicht. Ganze Antworten entstehen, indem es das immer wieder tut.
2. Text wird vorher in Zahlen übersetzt.
3. Die Vorhersage ist eine Wahrscheinlichkeitsverteilung, aus der gewürfelt wird. Darum antwortet ChatGPT auf dieselbe Frage nicht immer gleich.
4. Unser Bigramm kennt nur das letzte Zeichen. Das ist seine große Schwäche, und genau die beheben die nächsten Lektionen.
