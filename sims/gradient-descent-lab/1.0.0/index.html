Gradient descent labGradientenabstieg-Labor

Training a model means searching for the weights with the smallest loss. Gradient descent does it in small steps: look at the slope where you stand, then step downhill. Here you take the steps yourself, try different step sizes, and then let it fit a line to data.Ein Modell trainieren heißt, die Gewichte mit dem kleinsten Loss zu suchen. Der Gradientenabstieg macht das in kleinen Schritten: Schau, wie steil es dort ist, wo du stehst, und geh dann bergab. Hier machst du die Schritte selbst, probierst verschiedene Schrittweiten und lässt dann eine Gerade an Daten anpassen.

Station 1 · One weight, one valleyStation 1 · Ein Gewicht, ein Tal

Step downhillSchritt bergab

The model has a single weight w. Its loss is L(w) = (w − 3)², a valley with the lowest point at w = 3. You start at w = 0. Each step moves w against the slope, by the slope times the learning rate α = 0.1.Das Modell hat ein einziges Gewicht w. Sein Loss ist L(w) = (w − 3)², ein Tal mit dem tiefsten Punkt bei w = 3. Du startest bei w = 0. Jeder Schritt verschiebt w gegen die Steigung, um Steigung mal Lernrate α = 0,1.

Notice that the steps get shorter by themselves: near the bottom the slope is small, so slope times α is small too. Nobody has to tell the algorithm to slow down.Die Schritte werden von selbst kürzer: Nahe am Boden ist die Steigung klein, also auch Steigung mal α. Niemand muss dem Verfahren sagen, dass es langsamer werden soll.

The update rule is w ← w − α · L′(w) with L′(w) = 2(w − 3). Each step multiplies the distance to the minimum by (1 − 2α) = 0.8.Die Update-Regel ist w ← w − α · L′(w) mit L′(w) = 2(w − 3). Jeder Schritt multipliziert den Abstand zum Minimum mit (1 − 2α) = 0,8.

Each step multiplies the distance to the minimum by (1 − 2α). It shrinks only if |1 − 2α| < 1, that is 0 < α < 1. At α = 0.5 the factor is 0 and one step lands exactly on the minimum; that only works because this valley is a perfect parabola.Jeder Schritt multipliziert den Abstand zum Minimum mit (1 − 2α). Er schrumpft nur, wenn |1 − 2α| < 1 ist, also 0 < α < 1. Bei α = 0,5 ist der Faktor 0, und ein Schritt landet genau im Minimum; das klappt nur, weil dieses Tal eine perfekte Parabel ist.

Station 3 · A real modelStation 3 · Ein echtes Modell

Fit a lineEine Gerade anpassen

Now the model is a line y′ = w·x + b with two parameters, and the loss is the mean squared error (MSE) over eight data points. Training starts at w = 0, b = 0 and uses α = 0.15. One epoch is one pass over all points, followed by one step.Jetzt ist das Modell eine Gerade y′ = w·x + b mit zwei Parametern, und der Loss ist der mittlere quadratische Fehler (MSE) über acht Datenpunkte. Das Training startet bei w = 0, b = 0 mit α = 0,15. Eine Epoche ist ein Durchgang über alle Punkte, danach folgt ein Schritt.
