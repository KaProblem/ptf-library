Only the past countsNur die Vergangenheit zählt

A language model has to predict the next character at every position. To do so, each position may gather information from earlier positions, but never from later ones: that is where the answer is. Here you build the simplest way to do this and see how it turns into a tool called attention.Ein Sprachmodell soll an jeder Stelle das nächste Zeichen vorhersagen. Dafür darf jede Stelle Informationen von früheren Stellen einsammeln, aber niemals von späteren: Dort steht ja die Lösung. Hier baust du den einfachsten Weg, das zu tun, und siehst, wie daraus ein Werkzeug wird, das Attention heißt.

Station 1 · Try itStation 1 · Ausprobieren

Average of the pastMittelwert der Vergangenheit

Each of the eight positions carries a number; think of it as a property of that character. The simplest way to gather the past: each position takes the average of itself and all positions before it. Tap a position.Jede der acht Stellen trägt eine Zahl, stell sie dir als eine Eigenschaft des Zeichens vor. Die einfachste Art, Vergangenheit einzusammeln: Jede Stelle nimmt den Mittelwert aus sich selbst und allen Stellen davor. Tipp eine Stelle an.

Question:Frage: Which average does position 5 get?Welchen Mittelwert bekommt Stelle 5?

Station 2 · As a tableStation 2 · Als Tabelle

The triangleDas Dreieck

Write the averages as a table of weights: row = the position that gathers, column = the position it reads from. Each row spreads 100 % evenly over itself and its past. The top right stays empty: that is the future. Tap an empty cell to open the future and watch what happens.Schreib die Mittelwerte als Tabelle von Gewichten: Zeile = die Stelle, die einsammelt, Spalte = die Stelle, von der gelesen wird. Jede Zeile verteilt 100 % gleichmäßig auf sich und ihre Vergangenheit. Oben rechts bleibt alles leer: Das ist die Zukunft. Tipp ein leeres Feld an, um die Zukunft zu öffnen, und schau, was passiert.

Computationally this is one matrix multiplication: weights (8 × 8) times numbers (8 × 1) gives all eight averages at once. Because the lower-triangular matrix hides the future, it is called the causal mask.Rechnerisch ist das eine Matrixmultiplikation: Gewichte (8 × 8) mal Zahlen (8 × 1) ergibt alle acht Mittelwerte auf einmal. Weil die untere Dreiecksmatrix die Zukunft ausblendet, heißt sie kausale Maske.

Station 3 · Weights that can learnStation 3 · Gewichte, die lernen können

Scores, mask, softmaxPunkte, Maske, Softmax

Even weights are boring: maybe position 6 cares far more about position 2 than about the rest. So we give scores (affinities), set every future cell to −∞ and apply softmax to each row. With all scores at 0 you get exactly the triangle from station 2. Move the scores for row 6.Gleichmäßige Gewichte sind langweilig: Vielleicht interessiert Stelle 6 sich viel mehr für Stelle 2 als für den Rest. Dafür vergibt man Punkte (Affinitäten), setzt alle Zukunftsfelder auf −∞ und wendet in jeder Zeile Softmax an. Mit allen Punkten auf 0 kommt genau das Dreieck aus Station 2 heraus. Verschieb die Punkte für Zeile 6.

wei = q @ k.transpose(-2, -1)                    # scores (B, T, T)
wei = wei.masked_fill(tril == 0, float("-inf"))  # block the future
wei = F.softmax(wei, dim=-1)                     # each row sums to 1
out = wei @ v                                    # weighted average

Why −∞ and not 0? Softmax computes escore. e0 = 1 would be an ordinary weight; only e−∞ = 0 really blocks a cell. In a transformer the scores come from query times key: that is the next step.Warum −∞ und nicht 0? Softmax rechnet ePunkte. e0 = 1 wäre ein normales Gewicht, nur e−∞ = 0 sperrt ein Feld wirklich. Die Punkte selbst kommen beim Transformer aus Query mal Key, das ist der nächste Schritt.
